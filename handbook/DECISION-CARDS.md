# Creative Direction Decision Cards — 12 Short Rules

**Working v0.1.** Each card links to full research and requires task-specific judgment. These are *conditional heuristics*, not universal laws.

| Decision | Use when | Avoid when | Source |
|---|---|---|---|
| 01 Selective emphasis | One primary message/action needs attention | All elements competing | [Attention](../research/005-ARCHITECTURE-OF-ATTENTION.md) |
| 02 Relational color | Tuning hierarchy across surfaces | Color alone conveys meaning | [Albers reading](../reading-dossiers/001-ALBERS-ART-INSTRUCTION.md) |
| 03 Controlled variation | Many artists/campaigns share a platform | Changing interaction behavior for flair | [Scher case](../case-studies/art/001-PUBLIC-THEATER-IDENTITY-AS-SYSTEM.md) |
| 04 Visual restraint | High-frequency workflows | Removing useful labels/affordances | [Linear](../case-studies/digital/003-linear-2026.md) |
| 05 Emotional immersion | Narrative genuinely benefits | Blocking product information | [Cinematic research](../research/007-CINEMATIC-IMAGE-LANGUAGE.md) |
| 06 Clear function | User task is consequential | Decorative fake controls | [Component anatomy](../components/README.md) |
| 07 Typographic voice | Identity and culture matter | Long labels/legal/form copy | [Typography](../research/006-TYPOGRAPHY-AS-ARCHITECTURE.md) |
| 08 Art-directed cropping | Photographs carry subject meaning | Automatic crop cuts faces/story | [Photography](../research/007-CINEMATIC-IMAGE-LANGUAGE.md) |
| 09 Motion punctuation | Transition conveys change | Every element animates by default | [Frontend craft](../engineering/CREATIVE-FRONTEND-QUALITY.md) |
| 10 Three alternatives | Concept direction not yet settled | Three palettes of the same wireframe | [Anti-generic](ANTI_GENERIC-DESIGN-METHOD.md) |
| 11 State fidelity | Components communicate actions | Only screenshots of default state | [UX patterns](../components/forms-tabs.md) |
| 12 Evidence honesty | Evaluating outcomes | Unmeasured conversion/UX claims | [Research protocol](../docs/RESEARCH_PROTOCOL.md) |

## Card format for future work
**Situation → Source → Mechanism → Decision → Tradeoff → Failure test.**

## Quick critique
- Is this subject-specific?
- What is visually dominant and why?
- What is missing?
- Does it remain understandable without animations?
- Can keyboard, mobile and screen-reader users still act?
- What do we actually know versus merely predict?

If a card is routinely ignored or conflicts with tested outcomes, revise it. Do not bury failures.
