# Attention Direction — Field Checklist (Draft 0.1)

Use for critique or experimentation; **not** a proven universal formula.

## Before critiquing
- State user, task, environment, urgency, frequency and desired emotion.
- Identify primary and secondary decisions.
- Record actual viewport, input method, interaction state and whether the design was observed directly.

## Observe in three passes
1. **Three-second glance:** What attracts attention? Is it related to the task or only decoration?
2. **Normal reading:** What do the hierarchy, labels and imagery communicate?
3. **Interaction:** Does each significant visual cue correspond to a real action or useful content? Can the user recover?

## Inspect five factors
- Contrast and lighting: local, not only global.
- Direction: gaze, line, alignment and reading order.
- Exclusion: what has been intentionally removed and what information went missing?
- Meaning: is the visual metaphor culturally and contextually intelligible?
- Motion: is attention deliberately guided; can movement be reduced or paused?

## Test, don't assume
Do a first-click/comprehension test and a keyboard walk-through. Use accessible labels and visible focus. Observe mobile and zoom/reflow. Don't claim that viewing a screenshot proves animation, performance, or usability.

## Common anti-patterns
- Every element is visually primary.
- Stunning graphics but no clear next action.
- Low-contrast typography called "premium".
- Icon-only control with unknown meaning.
- Scroll animation blocking text or navigation.
- Artificially hiding information to manufacture an "immersive" experience.
