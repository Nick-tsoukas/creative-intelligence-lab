# Research to Design Direction — A Practical Synthesis Contract

**Status:** v0.1 draft for Creative Intelligence Lab. This document is not a certified design skill.

## Transform, don't transplant
Each source-backed reference should become a **conditional design action**:
- Source: named artifact, date and accessible link.
- Observation/fact: what is actually documented or observed.
- Mechanism: e.g. asymmetrical balance, high/low typographic tension, contextual color, controlled attention.
- Intended outcome: user meaning, comprehension, memory, task fluency.
- Context where appropriate.
- Known failure mode and accessibility tradeoff.
- A way to test it.

## Example 1
Scher's Public Theater work illustrates institutional coherence with variation across campaigns (source: Pentagram). Rather than copying its compressed fonts, decide which *interaction rules* remain stable and where expressive artwork can change for each campaign. If functional labels become illegible, the transfer has failed.

## Example 2
Tschichold's museum-documented asymmetrical layouts show that organized communication need not be symmetrical (source: MoMA). A digital layout can use asymmetry to highlight content but must preserve semantic reading order and reflow. If hierarchy depends on a fixed desktop size, the transfer has failed.

## Example 3
Müller-Brockmann's Beethoven poster uses geometric repetition to suggest movement (source: Smithsonian). A web experience can use rhythmic spacing and repeated shapes to establish coherence. If the motif displaces essential task controls, it has become decoration at the expense of meaning.

## Five questions before a visual decision is promoted
1. Would the decision still make sense if the reference image were hidden?
2. Does it emerge from *this* content or from a currently fashionable effect?
3. Is it meaningful enough to survive scaling and simplified motion?
4. Is the implementation cost proportionate to the improvement in understanding?
5. What experiment or critique would persuade us the decision is wrong?

## AI instruction
Never answer a creative brief with an unexamined single template. Return competing theses, expected strengths, tradeoffs and what needs human testing. Cite both art references and UX guidance when relevant. No production edits without explicit permission.
