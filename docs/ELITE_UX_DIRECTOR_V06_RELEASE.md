## Change and evidence

Owner-supplied Claude field feedback from Gallery work is REPORTED evidence, not an independently reproduced product audit. It reported value from action truth, impact disclosure, evidence labels and bounded repairs; defects arose in semantic order, sticky reachability, field visibility, font sizing and invalid captures. v0.6 preserves those strengths and adds a compact screen → action truth → intentional composition → render → inspect → repair → verify loop.

- Runtime core stays below 800 words; six focused references carry screen intelligence, action consequences, design-to-code checks, state/capture verification, visual craft/memory and research distillation.
- Personas, failure classes, smallest safe repair, server authority and truthful outcomes remain. One agent may perform distinct passes without pretending self-review is independent.
- Visual originality, composition, typography, image/space relationships and prior owner verdicts are explicit; technical checks do not certify beauty.
- Existing private visual workspace, decision artifacts, packet router and Interface Atlas are reused optionally. No new database, daemon, model API or schema.
- All book/source/card/homepage material and retrieval modes remain intact. Research primarily improves the skill through provenance, conditional mechanisms and real feedback. Routine implementation does not load the corpus.
- Dependency-free PNG capture checker detects corrupt streams, unexpected dimensions and suspicious nearly uniform tails. Exit 2 requests visual review; it is not a quality failure or completeness guarantee. State setup, scroll scope, actual image inspection and outcome tests remain necessary.
- Legacy tests require classification: retain behavior/accessibility contracts; replace obsolete taste expectations only under current authorized intent, with positive checks and an explanation.
