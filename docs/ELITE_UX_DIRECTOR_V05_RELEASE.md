# Elite UX Director v0.5 — Book-to-Design Intelligence Release

**Date:** 2026-11-15. **Package state:** confirm the final merged main commit and CI run before installation; this source document alone does not certify release. **Scope:** Creative Intelligence Lab research/skill architecture; NO Faneqo app code, live data, deployment, installed Windows skill, or active Claude session modified.

## Change thesis
**A deep source corpus is useful only if a skilled agent can retrieve a small, trustworthy mechanism when it changes a real decision.** v0.5 adds an actual study methodology, original-section reading records, visual evidence discipline, interdisciplinary conflict handling, nine new conditional K-cards and deterministic targeted retrieval without bloating every UX task.

## What's new vs v0.4
- Existing C01–C09, P1–P9 and H01–H08 unchanged; v0.4 homepage scope, role boundaries and Faneqo adapter preserved.
- Core `SKILL.md` modestly expanded with an **optional** book-intelligence route, not mandatory research on every UI task.
- `references/BOOK_STUDY_PROTOCOL.md`: edition/translator/rights checks, whole-book structure map, actual bounded chapters, author vs agent transfer, realistic read-status model and retention rules.
- `references/VISUAL_ANALYSIS_PROTOCOL.md`: must actually see the original artwork/page (or label a cropped/derivative visual appropriately); observe geometry, color, type and spacing separately from author intent.

- `references/CROSS_BOOK_SYNTHESIS.md`: reconcile disagreement without inventing scientific agreement between authors or universal beauty rules.
- `references/KNOWLEDGE_CARDS.md`: source-checked K01–K09: hierarchy, spacing, concept maps, user language, purpose, beauty vs usability, component/domain semantics, visual search and visual communication.
- `references/RESEARCH_INDEX.md`: choose cards by real problem and read status; if no source helps, use current product evidence.
- `scripts/retrieve.py`: keeps old card/pattern/homepage modes; adds `knowledge K03`, `list knowledge`, and `search "visual hierarchy"` returning only short ranked IDs.

- `sources/BOOK_CANON_RECONCILIATION_2026-11-15.md`: 82 incoming books and 40 other references reconciled against 130 legacy candidate rows, three newly verified complete online works, **ten additional publisher/authority-verified bibliography leads**.
