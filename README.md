## Research philosophy
- **Examine real work:** original paintings, primary artistic writings, architectural records, live websites, and working interfaces.
- **Classify knowledge:** documented facts, firsthand observations, practitioner views, interpretations, and hypotheses.
- **Evaluate both art and function:** spectacular design is not automatically usable; accessibility and performance are not optional.
- **Avoid magic formulas:** the golden ratio, eye-tracking myths, fashionable UX rules, and award-winning sites are subject to critical scrutiny.
- **Synthesize instead of imitate:** develop principles, counterexamples, and original hypotheses, not copies of distinctive creator styles.
- **Cite and respect copyright:** links rather than unauthorized book scans or copyrighted visual assets.

## Important current limitations
The original research session produced v0.1/v0.2 ZIP archives and preliminary long-form chapters. This initial GitHub collection contains a **curated onboarding and research scaffold**, not yet a verified full transfer of all older notes. Track that migration under [docs/STATUS.md](docs/STATUS.md) before claiming it completed. None of the reading queue implies a book was fully read.

## Product boundary
This repository does **not** host Faneqo application code. The eventual homepage redesign is deferred. Do not modify Faneqo's frontend or backend, create or install a Claude skill, or deploy code without explicit user authorization.
