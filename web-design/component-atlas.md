# UI Component Pattern Atlas

A component is not merely its appearance. Study the complete **interaction contract**: keyboard, focus, state, feedback, error, responsive, accessibility, and data conditions.

## Families
1. Navigation: global nav, mobile menu, breadcrumbs, tabs, command palettes.
2. Inputs: text fields, combobox, search, segmented control, sliders, date inputs.
3. Feedback: toast, status, alert, progress, empty, loading, error and success.
4. Overlays: dialog, drawer, popover, tooltip, lightbox.
5. Collections: lists, grids, filtering, sorting, pagination, virtualized views.
6. Content: galleries, media players, editorial layouts, previews and carousels.
7. Complex work: dashboards, data tables, charts, editors, upload flows.
8. Commerce and finance: checkout, payment confirmation, receipts and refunds.
9. Identity: sign-in, account recovery, permissions and security states.
10. Creative systems: timeline controls, animation preview, artboards and asset pickers.

## For each pattern record
Purpose; user goal; examples; variant tradeoffs; mobile; keyboard/focus; screen reader expectations; loading/error/empty states; reduced motion; implementation complexity; usability research; accessibility standard; failure cases.
