# Web Design, UX & Components Research

We maintain two complementary atlases:

1. **Extraordinary digital experiences:** experimental compositions, cinematic storytelling, typography, expressive interactions, and artistic identity.
2. **Exemplary interfaces:** clear navigation, accessible and predictable interactions, proven UX principles, error handling, performance, mobile behavior.

An impressive screenshot is neither a UX audit nor proof of implementation quality. An award is discovery evidence, not quality proof.

## Research streams
- Curated live sites and agency case studies: see `experience-atlas.md`.
- Evidence-based UX source catalog: see `sources.md`.
- Components/pattern families: see `component-atlas.md`.
- Dated trend watchlist: see `trends.md`.
- Reusable case study form: see `../templates/DIGITAL_CASE_STUDY.md`.

## Standards
Record URL, observed date, actual interaction performed (if any), viewport/device, visual quality, usability tradeoffs, accessibility limitations, and technical claims verified with evidence. Do not claim web technology from appearance alone.
