# Visual Grammar Studio — One brief, three genuinely different compositions

**Status:** original, self-contained practice artifact. **No Faneqo code or production assets.** It is a deliberately fictional design challenge, not a real customer, verified conversion claim, or visual study of a specific contemporary website.

The design question: can a research-led art director make **three conceptually different** visual arguments using identical product copy, real links and conditions, not simply swap color palettes?

## Open and use
Open `index.html` in a modern browser. Choose **Editorial / Cinema / Signal** buttons. The underlying primary statement, supporting copy, links, utility information and page sections stay identical. Each composition changes dominant visual mass, typography, rhythm, supporting shapes and how an “after the performance” metaphor is conveyed.

All graphics are original CSS compositions, not imitations of Hokusai, Scher, Blue Note, Hopper or an artist's photograph. The fictional product “Encore Notes” is a studio-only demonstration; it has no artists, users, sales statistics, endorsements or real signup. The primary CTA is an actual in-page anchor to the product-explanation section, explicitly labeled **Explore the concept** (not a fake signup).

## Three artistic hypotheses
| Mode | Thesis | Arrangement | Why it can fail |
|---|---|---|---|
| Editorial | A night deserves a physical document | Strong readable title and marginalia, paper texture, restrained spatial groupings | Can look too ordinary or archival for an energetic live act |
| Cinema | The stage ends, the story continues | Atmosphere/spotlight, staged central depth and grounded action | Cinematic effect can hide a button or overload low-end devices |
| Signal | Music is a bold mark that continues | Atypical scale, typographic blocks, high-contrast visual punctuation | Poster vocabulary can overwhelm long names and mobile reading |

**Never claim these are tested artistic masterpieces.** They are controlled originals intended to help a critic compare decisions under constant content, not an endorsement of three template families for every brand.

## Evidence exercises
1. **First-glance task:** ask an unfamiliar person what the fictional product is for and where the concept explanation is. Don't coach them. Record response, not an invented success score.
2. **Focal-route map:** at 390px and 1440px write what appears primary/secondary, then check if the design's thesis matches the reading route. Don't claim this is eye-tracking.
3. **Mobile / text stress:** test 320px, 390px, 768px, desktop; 200% text enlargement; long band/product names; 320px reflow and override text spacing. No clipped text/hidden CTA.
4. **Reduced motion / no JS:** verify links and core content work with motion preference and Javascript disabled. Buttons that switch views need JS; lack of switching isn't core-product data loss.
5. **Critic disagreement:** ask independent reviewers to separately evaluate artistic originality, cultural authenticity, product meaning, usability/accessibility and implementation. Document counterexamples and dissent.
6. **Promote or reject:** only preserve a demonstrated transferable mechanism, never copy a famous visual treatment.
