# Claude Code — Creative Intelligence Lab

This repository is a **research knowledge base**, not an application.

On session start:
1. Read `START_HERE.md`, `docs/STATUS.md`, `docs/HANDOFF.md`, `ROADMAP.md`, and `docs/RESEARCH_PROTOCOL.md`.
2. State what is verified versus queued or only preliminarily studied.
3. Ask for explicit authorization before any Faneqo app change, deployment, or skill installation.

When asked to research:
- Prefer primary sources, original works, officially documented implementations, and credible UX studies.
- Keep fact, direct observation, artist intention, interpretation and untested hypothesis separate.
- Never invent quotes/page numbers/links or claim full book reading without access.
- Describe limitations of screenshot-only or desktop-only UX assessments.
- Add meaningful findings to the appropriate Markdown file; update STATUS and CHANGELOG if changed.
- Compare aesthetics with usability, accessibility, mobile and performance.
- Do not copy other studios' visual identity; synthesize principles.
- Do not commit third-party copyrighted source files without permission.

The owner intends a **future optional reusable art-direction skill**. This CLAUDE.md is an onboarding file, **not** that skill.

Focus near-term on high-quality case studies of digital experiences and component patterns, with cited evidence and counterexamples.
