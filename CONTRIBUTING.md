# Contributing to the Creative Intelligence Lab

1. Check START_HERE, STATUS and ROADMAP before editing.
2. Add sources with citation and access-status labels; never falsely claim full text was read.
3. Distinguish sourced fact from observation, critique, and hypothesis.
4. Prioritize concrete analyses of real work over generic reference lists.
5. For web case studies, document what was actually viewed or tested, on what device and date.
6. Include examples where techniques fail; avoid blindly following design trends.
7. Preserve third-party copyrights; link rather than commit unauthorized materials.
8. Keep edits reviewable. Update STATUS/CHANGELOG and cross-reference affected notes.
9. Never edit Faneqo production repositories, deploy, or create a Claude Code skill based solely on these research instructions.
10. Do not commit secrets, personal data or private client content.
